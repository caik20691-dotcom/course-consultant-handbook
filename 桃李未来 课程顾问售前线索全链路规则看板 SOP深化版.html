02
新签客户定义 · A / B / C / D 四类型
CUSTOMER TYPE

新签客户的判定是课程顾问工作分工的核心依据，所有分配与流转均以此为基础。客户按在读与课消状态分为四种类型，其中类型 A、B 归课程顾问新签，类型 C 归课程顾问促加报，类型 D 归教务维护。

TYPE · A
全新客户
（从未在读）
从未在本机构报名过任何课程的家长 / 学员。最常见的新签场景，各触点进线均适用。
课程顾问 · 新签
系统无学员档案，或档案中无任何历史订单
TYPE · B
历史流失客户
（超 2 学期无课消）
曾经在读，但距上次实际上课已超过 2 个完整学期，且当前无未消耗课时。
课程顾问 · 新签
当前日期 − 最后课消日 > 2 学期(约8月) 且 课时余额=0
TYPE · C
在读无当前课消
（促加报）
当前有未开课 / 进行中课程，但本学期内尚无实际课消记录。
课程顾问 · 促加报
有效合同 + 课时余额>0 + 本学期课消=0
TYPE · D
在读且正常课消
（教务维护）
当前学期有实际课消记录，且课时余额>0。课程顾问不可介入。
教务 · 维护
有效合同 + 本学期有课消 + 余额>0
促加报 ≠ 新签 类型 C（在读无当前课消）由课程顾问负责促加报，但促加报不等于新签——须用促加报话术，不可用新签话术。类型 B（历史流失）虽曾在读，但因超 2 学期无课消已脱离正常服务轨道，必须由课程顾问按新签流程重新跟进，不得归教务。

重要边界说明

编号议题说明
B012 学期的时间计算以自然学期为单位：秋季(9月–次年1月) / 春季(2月–6月) / 暑假(7–8月) / 寒假(1–2月)。超过 2 个完整自然学期无课消即满足类型 B。暑期短期课不计入正式学期。
B02课时余额 ≠ 在读家长账户有余额但已超 2 学期未上课的，仍判定为类型 B（课程顾问新签），而非教务维护。余额问题由教务协助退课或说明，课程顾问专注重新销售。
B03多孩家庭同一家长名下多个孩子时逐孩判断。A 孩子在读（类型 D）不等于 B 孩子在读，B 孩子的线索按各自标准独立判定。
B04特殊品类人机课、短期集训营等非常规品类的在读判定标准，由中台运营另行发文明确，本看板暂不覆盖。
SOP接到线索 → 客户类型识别 操作三步法
每条线索分配后，顾问首触前必须先在 CRM 完成类型识别，决定用「新签 / 促加报 / 退回教务」哪套打法。
1
查档案 30 秒
CRM 输入家长手机号 → 看是否存在学员档案。无档案 = 类型 A 全新客户，直接走新签；有档案进第 2 步。
2
查合同与余额 30 秒
看是否有有效课程合同（未结束 / 余额>0）。无有效合同 → 进第 3 步判断流失；有合同 → 看本学期课消（有课消=类型D退教务，无课消=类型C促加报）。
3
算流失时长 30 秒
查最后一次实际课消日期：距今超 2 个完整学期 = 类型 B（顾问按新签重启）；不足 2 学期 → 进观察池，暂不主动激活。
关键动作识别完成后，在 CRM「客户类型」字段打标（A/B/C/D），这是后续分配、考核、业绩归属的统一依据，不可不填或填错。
类型 B 激活 SOP（历史流失客户）
① 调阅历史学情与流失原因（教务协查）→ ② 首触不提续费先做关怀，了解孩子现状 → ③ 用"老学员专属回归礼"破冰 → ④ 邀约到店重新测评 → ⑤ 按新签流程谈单。切忌一上来就催报名。
类型 C 促加报 SOP（在读无课消）
① 联合教务确认未课消原因（没排上课？时间冲突？观望？）→ ② 解决课消障碍优先于加报 → ③ 待正常课消后再切入加报场景（加科目/加课时）→ ④ 用促加报话术，不可用新签话术。
💬促加报话术（类型 C 专用，区别于新签）在读无课消客户
场景家长已报名但本学期一直没来上课，顾问推进其开始课消并考虑加报。
顾问开场"X 妈妈您好，我是 XX 校区的课程顾问 XX。注意到 XX 同学这学期的课时还一直没开始用，我有点担心耽误孩子的学习节奏，特地联系您看看是时间不方便还是有其他顾虑？"
推进"咱们先把现在的课时安排上，让孩子学起来。等孩子上了几次课、状态稳定了，我再根据老师反馈看看要不要给薄弱的科目补一补，这样最稳妥。"
注意促加报客户已是付费学员，话术核心是"帮孩子用好已购课时 + 顺势加报"，绝不能用对待新客户的"从零介绍课程、逼单成交"话术，否则引发反感。
03
七大流量触点 · 留资规范
7 TOUCHPOINTS SOP

课程顾问需承接七大流量触点，每个触点从「进线动作 → 规范操作 → 首触要求 → 注意事项」全链路标准化。 所有触点均须在 CRM 中强制标注「渠道来源」字段，不填渠道来源的线索不予分配，责任由课程顾问承担。

触点规范操作（SOP）首触时效必填 CRM 字段 / 注意事项
① 直电进线
（电话呼入）		接听 5 秒内自我介绍 → 确认孩子年级/科目/需求 → 30 分钟内录入 CRM 并评级 → 即时发企微好友接听即首触
CRM 录入 ≤30min		手机号 / 渠道=直电 / 意向级别 / 需求关键词。
注意：无人接听需回拨（≤3 次/天）；勿在首通电话直接报价
② 直访进线
（到店咨询）		3 分钟内主动接待、引导就坐 → 六步法挖需 → 当场用 PAD/手机录入 CRM → 加企微发资料到店即首触
录入 ≤当日下班前		手机号 / 渠道=直访 / 到访日期 / 意向级别 / 面谈摘要。
注意：必须当场加企微，不可仅留电话；面谈记录须同步 CRM
③ 线上引流
（广告/SEO/信息流）		系统自动分配或当天录入 → 24h 内首触（优先电话，未通改企微+短信）→ 关联广告卖点定制首句 → S/A/B/C 评级系统分配后 24h 内手机号 / 渠道=平台名称 / 广告素材 ID / 意向级别。
注意：来源须精确（抖音/小红书/百度要区分，勿填"线上"）；话术须关联广告内容
④ 转介绍进线
（老带新）		第一时间感谢介绍人 → 30 分钟内联系被介绍人（提及介绍人建立信任）→ CRM 标注介绍人信息 → 签约后结算奖励收到信息后 30 分钟内手机号 / 渠道=转介绍 / 介绍人姓名 / 与被介绍人关系。
注意：须关联介绍人学员 ID 否则奖励无法结算；归属争议以 CRM 录入时间为准
⑤ 统测/活动进线
（讲座/测评/体验课）		活动当天录入（标注活动全称）→ 24h 内电话反馈测评/体验结果 → 结合测评定制话术 → 高意向当天约下次到访活动结束后 24h 内手机号 / 渠道=活动名称+日期 / 测评成绩 / 意向级别。
注意：来源填活动全称（如"2026年5月28日散测"）；测评报告须附上
⑥ 在线表单/官网留资系统推送 CRM → 24h 内电话触达 → 查看家长填写意向定制话术 → 电话+企微双通路 → 补齐客户档案表单提交后 24h 内手机号 / 渠道=官网/小程序/H5（区分）/ 表单科目意向。
注意：来源须区分三类，影响转化数据分析；表单信息须完整迁移 CRM
⑦ 二维码扫码
（海报/地推/物料）		触发后 30 分钟内联系（含企微欢迎语）→ 确认扫码来源标注 CRM → 推送对应活动/课程 → 引导到访预约扫码后 30 分钟内手机号 / 渠道=二维码+物料名称 / 地推位置。
注意：不同二维码用不同参数追踪；地推顾问须实名标注，防止抢单
SOP电话首触 5 步法（直电 / 线上引流 / 活动回访通用）
电话是售前最高频的首触方式。一通好的首触电话，目标不是成交，而是"建立信任 + 拿到需求 + 约下一步"。
1
开场报名（5 秒内）
"您好，我是桃李未来 XX 校区课程顾问 XX"——报清机构+校区+身份，建立正规感，降低戒备。
2
说明来意（关联来源）
关联客户的进线来源（看了哪条广告/参加了哪场活动/谁介绍的），让家长想起"我确实留过资"，而非陌生推销。
3
挖需求（3 问）
问孩子年级 → 薄弱科目 → 当前最头疼的问题。多听少说，记录关键词，为后续定制方案铺垫。
4
给钩子 + 约到店
用"免费学情测评 / 体验课 / 诊断报告"做钩子，给两个具体时间二选一约到店（"您看周六上午还是周日下午方便？"）。
5
加企微 + 录 CRM 通话后即时
挂电话前主动加企微，挂断后30 分钟内录入 CRM + 完成 S/A/B/C 意向评级。不可只在脑子里记。
首触红线① 勿在首通电话直接报价；② 无人接听需回拨，每天不超过 3 次；③ 未接通改企微+短信同步触达。
SOP直访接待 · 面谈六步法（到店 → 签约）
到店客户意向最高、最值钱。六步法是把"到访"转化为"签约"的标准接待动作。
1
迎接破冰（3 分钟内）
起身迎接、引导就坐、递水，先聊孩子不聊课程，营造轻松氛围，建立第一印象信任。
2
需求挖掘
问现状（成绩/排名）→ 问期望（目标）→ 问痛点（最急的问题）→ 问决策（谁做主/预算概念）。挖得越深，方案越准。
3
测评诊断
安排学科测评或调出测评结果，用客观数据暴露问题，让家长意识到"确实需要补"，而非顾问空口说。
4
方案呈现
基于诊断给个性化学习方案（科目/课时/老师/周期），把方案和孩子的具体问题一一对应，体现专业与针对性。
5
价值塑造 + 报价
先讲价值（效果/师资/服务）再报价，用"每节课成本/孩子收益"对比化解价格异议，适时给限时优惠促决策。
6
促成签约 / 未签当日跟进
临门一脚逼单（名额/优惠紧迫感）。当场签约最佳；未签当日或次日必跟进，趁热打铁，状态置 S8→S11 或 S8→S3。
💬转介绍首触话术（提及介绍人建立信任）收到信息 30 分钟内
顾问"X 妈妈您好，我是桃李未来的 XX。是 XX 同学的妈妈 把您的联系方式推荐给我，说您家孩子也在找 XX 科目 的辅导，特地联系您了解一下孩子的学习情况~"
要点第一句必须点出介绍人——这是转介绍最大的信任杠杆。同时第一时间私信感谢介绍人，告知"已联系上"。
CRM录入时必须关联介绍人学员 ID + 标注关系，否则签约后介绍奖励无法结算，引发介绍人投诉。
04
意向评级 · S / A / B / C 四级
INTENT GRADING
概念区分 请勿混淆两套分级：「客户类型 A/B/C/D」（第 02 章）是按在读与课消状态划分的归属依据；「意向评级 S/A/B/C」（本章）是课程顾问首触后按成交意向强弱打的跟进优先级标签。两者维度不同，并行使用。
S
极高意向
判定：明确预算+明确科目+期望近期开课+主动询价，可当天约访
高意向当天约下次到访
A
高意向
判定：有明确需求且沟通积极，预算或时间待敲定
优先重点跟进
B
中意向
判定：有一定意向但观望/比较/资金待定，进培育池
每 1-2 周轻量触达
C
低意向
判定：需求模糊、态度一般，长周期培育
定期培育，30天无互动入公海
评级动态化 意向评级在首触后录入，并随跟进进展动态修订（如 C 升 A 或 A 降 B），系统记录每次变更及原因。评级直接影响该线索的跟进优先级与培育节奏。

公海管理 · 到访接待对应
PUBLIC POOL & VISIT

一、公海层级 · 只设校区公海，不设片区公海

公海划分结论 公海只做「校区公海」，不做「片区公海」。 线索天然绑定校区（客户就近上课），校区公海由本校区顾问捞取，符合就近服务原则； 片区层定位是「监督 + 跨校区仲裁 + 资源调剂」而非持池。当某校区公海积压严重或线索枯竭时，由片区主管发起临时跨校区调剂（一事一议），而非常设片区公海，以避免跨校区抢单与客户被分至远校区。

二、入公海与捞取规则

📥 入公海触发

满足任一条件，线索由顾问名下移入校区公海
  1. 3 天无有效跟进（仅发消息无回复不算）第 4 天 0 点自动入
  2. 无法联系满 7 天：连续 3 次无接通 + push 无响应
  3. 培育池 30 天无互动
  4. 顾问离职且未完成交接

📤 公海捞取规则

顾问从本校区公海主动捞取，重新进入个人跟进池
  1. 可见范围：本校区公海对本校区顾问可见
  2. 捞取上限：每天 X 条，按积分/等级上限不同
  3. 捞取后：24h 内必须有效触达
  4. 未触达：自动退回公海并扣分
  5. 系统唤醒：公海线索每周自动发干货尝试唤醒

三、上门到访 ↔ 接待顾问对应关系（双轨制）

已邀约到访

APPOINTED VISIT
顾问主动邀约而来的客户，由邀约顾问本人接待。

理由：已建立信任与完整跟进记录，保持服务一致性；业绩归属清晰，对应状态 S5 邀约确认 → S8 已到访。

若邀约顾问当日不在，由主管指定同组顾问代接待，归属仍计原邀约顾问。

自然到访（无预约）

WALK-IN VISIT
家长直接上门、系统中无归属顾问的客户，由当班轮值顾问接待，接待即归属（先到先得）。

对应「直访进线 = 指定分配、到店即首触」。

前台/CRM 在到访登记时自动核验手机号是否已有归属顾问——有则通知原顾问接待，无则按轮值分配。
到访接待铁律 一切到访先在 CRM/前台查归属：有归属 → 原顾问（或其代接人）接待；无归属 → 轮值接待并即时建档归属。 严禁多名顾问现场争抢同一到访客户，违者按抢单争议（E1）处理。
公海捞取 SOP（捞得准、用得上）
① 看公海线索的历史跟进记录与入海原因（别捞死单）→ ② 优先捞曾有有效沟通、近期入海的线索 → ③ 捞取后 24h 内必须有效触达（电话接通或企微回复）→ ④ 触达后立即更新意向评级、建跟进计划。未触达自动退回并扣分，别占着不跟。
入公海预警 · 自救 SOP
系统在线索掉入公海前 1 天发预警。收到预警后：① 立即检查该线索为何 3 天无有效跟进 → ② 当天补一次有效触达（不是发条消息，要拿到回复）→ ③ 更新跟进记录与状态。有效跟进后即可避免掉入公海。别等掉了再捞回来浪费保护期。
SOP到访登记 · 归属核验动作（前台/顾问）
这是"双轨到访"落地的关键——任何客户到店，先查归属，再定接待人。
1
到店即录手机号查归属
前台/接待顾问第一时间用手机号在 CRM 查询，判断是否已有归属顾问。
2
有归属 → 通知原顾问
已有归属（多为已邀约客户）→ 由原邀约顾问本人接待；原顾问不在则主管指定代接，归属仍计原顾问。
3
无归属 → 轮值接待即归属

异常处理与仲裁 · E1–E6
DISPUTE & ARBITRATION

覆盖线索链路常见异常场景，明确认定标准、处理流程与处罚规则。 总原则：私下交易零容忍 / 虚假跟进与恶意标记二次警告 / 所有争议 24h 内响应裁定。所有处罚由片区主管最终确认，中台存档。
