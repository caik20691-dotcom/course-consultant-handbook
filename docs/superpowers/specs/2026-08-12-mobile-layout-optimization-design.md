# 课程顾问岗位手册手机端优化设计

## 目标

在不修改页面内容、配色与桌面端视觉结构的前提下，改善 `课程顾问岗位手册.html` 在 320–768px 宽度设备上的阅读、导航和触控体验。

## 范围

- 保留现有数据、栏目结构、桌面端布局和打印样式。
- 重构手机端响应式 CSS，减少依赖内联样式匹配和 JavaScript 强制改写布局。
- 优化顶部栏目选择、二级导航、卡片、流程区域、详情折叠项和数据表格。
- 不引入构建工具、框架或外部运行时依赖。

## 方案

采用“CSS 响应式重构 + 少量 JavaScript 状态同步”。为动态模板中的主要布局补充语义化 class，由媒体查询控制手机端表现；删除 `fixMobileGrids()` 对渲染结果的运行时遍历和内联样式覆盖。现有选项卡及内容渲染逻辑保持不变。

## 手机端布局

- 页面外层在 320px 宽度下不得产生整体横向滚动。
- 页头压缩留白和装饰元素，避开固定菜单按钮。
- 主栏目选择器在滚动时保持可见，并清楚显示当前栏目。
- 二级导航保持单行横向滚动，提供边缘渐隐或其他可感知的可滚动提示。
- 双栏、三栏、指标和流程布局在手机端自然切换为单列；文本、徽章和长链接允许安全换行。
- 表格保留表格语义，只在自身容器内横向滚动；加入简短滑动提示，不压缩到不可读。
- 交互控件的有效触控高度不小于约 44px，并保留清晰的键盘焦点样式。

## 行为与兼容性

- 切换主栏目后，手机选择器与当前内容保持同步。
- 打开侧边菜单后锁定背景滚动；关闭、选择项目或进入桌面宽度时恢复。
- 页面在旋转及视口尺寸变化后由 CSS 自动重排，不运行逐元素修复脚本。
- 尊重 `prefers-reduced-motion`，减少非必要动画。

## 验证

- 在 375×812、390×844、430×932 三组手机视口检查所有主栏目。
- 检查 320px 极窄视口没有页面级横向溢出。
- 检查所有表格可在容器内部滚动，首尾列均可访问。
- 检查主栏目、二级导航、折叠项和手机菜单可触控与键盘操作。
- 在桌面视口回归页面布局，并运行 HTML/JavaScript 基础语法检查。

## 非目标

- 不改写业务文案或数据。
- 不重新设计品牌视觉。
- 不改变桌面端的信息架构。
- 不发布、推送或创建 Pull Request，除非用户另行授权。
